# 素材一覧（すべて仮素材）

試作版の絵・音は、**外部の画像・音源ファイルを使わず、プログラムで描画・演奏**しています。完成版の素材ではありません。
既存作品の画像・音楽・キャラクターをまねたものではなく、ライセンス上の制約がある素材は含みません。

| 種類 | 作り方 | 場所 | 状態 |
| --- | --- | --- | --- |
| 灯獣の絵（151種） | 手書きの SVG（最初の23種は1体ずつ描き、2つ目の町以降の77種と さいはて諸島の50種は 体の形・段階・色・属性の飾りの設計図から組み立てる。左右対称に描く。進化前は丸い目のかわいい姿、進化後はつり目、最終進化は光る目とオーラ。炎／うろこ／毛並みの部品）＋ SVG フィルターで陰影・つや・きめを付ける | `src/art/monsterArt.ts` | 仮 |

## 外部のライブラリ（第三者のソフトウェア）

| 名前 | 版 | ライセンス | 使いみち | 読みこむ時 |

「QRコード」は株式会社デンソーウェーブの登録商標です。

## BGM の割り当て

要件で挙げた場面と、使っている曲の対応です（ゲーム内の 設定 →「BGMの対応表」でも見られます）。
試作版では曲数を抑えるため、一部の場面は別の曲で代用しています。

| 場面 | 曲 | 状態 |
| --- | --- | --- |
| タイトル画面 | title | 実装 |
| 通常の町 | town | 実装 |
| 重要な町 | town | 代用 |
| フィールド | field | 実装 |
| 森林 | forest | 実装 |
| 洞窟 | forest | 代用 |
| 通常戦闘 | battle | 実装 |
| ボス戦 | boss | 実装 |
| 伝説級の灯獣との戦闘 | boss | 代用 |
| 進化 | evolution | 実装 |
| 重要イベント | indoor | 代用 |
| エンディング | ending | 実装 |
| クリア後の高難易度 | boss | 代用 |

このほか、屋内用（indoor）と勝利のファンファーレ（victory）があります。

正確な一覧は `src/audio/music.ts` の `BGM_PLAN` です。

## 完成版に向けて

- 灯獣・人物・タイルはイラストレーターへの依頼、または権利がはっきりした素材への差し替えが必要
- 差し替えの入口：灯獣は `art` ID ごと、タイルは文字ごとに描画関数が分かれているので、画像を読み込む形に置き換えやすい
- 音楽・効果音も同様に、`TRACKS` / `se()` の中身を音声ファイルの再生に置き換えればよい
