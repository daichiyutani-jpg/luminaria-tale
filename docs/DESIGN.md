# 設計書：ルミナリア・テイル ～灯獣の島～

最終更新：2026-11-05（0.2.0：10の町・100種・ジム・ボス・2周目）

## 1. コンセプト

- スマホ縦画面・片手で遊べる、オリジナルのモンスター育成RPG
- 「灯（ともしび）」を胸に宿す生き物＝**灯獣（ともしびけもの）** を捕まえ、育て、進化させる
- ひとり用は完全オフライン。通信（対戦・交換）は QR コードで部屋に入る方式（設計のみ・未実装）

既存作品の名前・キャラクター・地名・技名・音楽は使っていません。灯獣の名前・姿・技・世界観はすべて新規です。

### 第1章「ほたる森の 灯」（試作版の範囲）

1. 自分の家で目覚める → 研究所でソラネ博士から相棒（3体から1体）をもらう
2. ライバルのカイトと最初の勝負（負けても話は進む）
3. 博士から依頼：北の「ほたる森」に黒霞が出た
4. そよかぜ草原：見習いトレーナー、花屋、釣り人、迷子のフワモ探し（サブクエスト）
5. ほたる森：静夜団のしたっぱ×2、カイトと協力、3つの灯籠柱に灯をともす（謎解き）→ 黒霞が晴れる
6. 森の主ホタルノオウ戦（ボス）→ 正気に戻り「ほたるのはね」をくれる
7. 博士に報告 → 第1章クリア画面（その後も草原・森で育成とサブクエストを続けられる）

## 3. ゲームの仕組み

### 属性（9種）と相性

ふつう／ほむら（炎）／しお（水）／めぶき（草）／いかずち（雷）／いわお（岩）／はやて（風）／ひかり（光）／かげ（影）

- ほむら → めぶき → しお → ほむら の三すくみ（最初の3体）
- いかずちは しお・はやてに強く、いわおは ほむら・いかずちに強く、はやては めぶき・いわおに強い
- ひかりとかげは互いに弱点を突き合う
- 効果なし（0倍）は作らない。ばつぐん 2倍／いまひとつ 0.5倍、同じ属性の技は 1.25倍
- 相性表はゲーム内の「図鑑 → 相性表」で見られる。正本は `src/data/elements.ts`

### 灯獣（100種・47系統）

進化の割合は **系統の数で「進化なし 2割・1回進化 5割・2回進化 3割」**（2026-11-04 決定）。`tests/logic.test.ts` で割合が崩れていないか確かめている。灯獣を足す時もこの割合を保つ。100種では割り切れないため、47系統で 進化なし10（21%）・1回進化23（49%）・2回進化14（30%）とし、テストは ±3% 以内で確かめる（2026-11-05）。（伝説のチョンボを入れる時、仮置きだったコダマザルと入れ替えて割合を保った）

見た目の決まり（2026-11-04 決定）：**進化前はかわいく（大きな丸い目・丸い体）→ 進化するたびにカッコよく強そうに**（つり目・鋭い部品）。最終進化は光る目とオーラで いちばん強そうにする。

- ほたる森の主 ホタルノオウを倒すと、泉であずかっていた子（Lv12）
- ジム3 しおさい港のナギサに初めて勝つと、港に流れついた子（Lv20）
- パーティー（6体）がいっぱいならボックスへ送る。トレーナーが連れているのはかまわない

序盤の手ごたえ調整（2026-11-05）：草原・森の野生を1レベル下げた。花屋ミオ・釣り人ゲン・静夜団のしたっぱも1レベル下げ、技選びの賢さも下げた（ライバル0.3・ユウ0.4・ミオ/ゲン0.5・したっぱ0.6）。森の主は Lv13。町のジムと道のトレーナーは、進むにつれて賢くなる（ジム1は0.6 → ジム6以降は0.85）。

2つ目の町から先で出会う 77種（2回進化11系統・1回進化18系統・進化なし8種）は `src/data/speciesExtra.ts` にまとめてある。能力値は「役割（攻撃型・耐久型など）× 進化の段階」から、覚える技は属性から計算する。絵は `src/art/monsterArt.ts` の設計図（体の形10種類 × 段階 × 色 × 属性の飾り）から描く。

分岐進化は、条件を満たした候補が複数あると「どの姿へ進化させる？」の選択画面になり、能力の増減と役割を見比べて選べます。進化はいつでも取りやめでき、あとでメニューの「なかま」から進化させることもできます。

### 戦闘

- 1対1のターン制、なかまは最大6体（7体目からはボックス。2026-11-05 に3体→6体へ変更）
- コマンド：たたかう（技は最大4つ・PP制）／なかま（交代）／どうぐ／つかまえる・にげる（野生のみ）
- 状態異常：やけど・どく・まひ・ねむり・かすみ（命中低下）。同じ属性の灯獣は一部の状態異常にかからない
- 能力変化（±6段階）、急所、命中、素早さ順、先制技
- 経験値は戦闘に出た味方で分け合う。トレーナー戦は1.4倍。2026-11-05 にレベル上げを少し楽にするため全体を1.25倍にした（同じレベルの野生で1レベル上げるのに Lv15で約2.6体・Lv30で約5体。以前の約8割）
- 全滅すると所持金の1/4を落とし、最後に休んだ場所へ戻る（自動セーブ）
- メッセージの速さは3段階＋アニメーション短縮（戦闘中の「はやい」ボタン・SELECTボタンでも切替）
- 画面配置：敵は右上（HPは左上）、味方は左下（HPは右下）、下にメッセージとコマンド。絵とHP表示が重ならないよう `src/ui/battleLayout.ts` の同じ計算で並べる（e2e で重なりを検査）

### 捕獲

- 相手のHPが少ないほど・状態異常があるほど・ランタンが良いほど捕まえやすい（ともしび1倍／あかり1.5倍／たいよう2.2倍）
- 判定は4回、ランタンが最大3回ゆれる演出。計算式は `src/logic/capture.ts`
- 成功率の上限は 85%（`MAX_CAPTURE_CHANCE`）。どんなに弱らせても・良いランタンでも、ランダムで逃げられることがある

### 成長

- レベル上限100。経験値曲線 `0.8 × Lv³`
- 能力値は種族値・レベル・素質（0〜15）から計算
- 技を4つ覚えている時に新しい技を覚えると、入れ替えるか確認する

## 4. 画面とデータの分離

- コンテンツ（灯獣・技・道具・相性・マップ・人物・会話・クエスト・お店）は `src/data/` にだけ書く
- 戦闘・捕獲・成長などの計算は `src/logic/`（画面に依存しない。乱数を差し替えてテストできる）
- 見た目（Phaser）と文字・メニュー（DOM）は分離。文字はすべて DOM なので、小さな画面でもにじまず読みやすい

## 5. セーブ

- 保存先：ブラウザの IndexedDB（3スロット＋設定）
- 1回の保存で「本体」と「ひとつ前の本体（バックアップ）」を同時に書き込み、チェックサムで破損を検出。本体が壊れていればバックアップから復元
- 版番号つき。古い版のセーブは移行処理（`MIGRATIONS`）で新しい形式へ変換。新しい版で作られたセーブは読み込まずに案内を出す
- 上書き・削除の前に必ず確認（削除は2回確認）
- 書き出し（ファイル）／読み込み。読み込み時は能力値・技・進化の記録を厳しく検査し、不正なデータは拒否
- 「セーブデータを消されにくくする」（ブラウザの永続化の申請）と、データが消える場合の注意書きを表示

## 6. PWA・オフライン

- `sw/sw-template.js` にビルド時の版とファイル一覧を埋め込み、版ごとの別キャッシュに全ファイルを保存
- 新しい版が届いたら「更新があります」と知らせ、切り替え時は古いキャッシュを消す（新旧が混ざらない）
- 設定画面で「オフラインで遊べるか」を実際のキャッシュ内容から確認して表示
- ひとり用の部分は外部への通信がゼロであることを e2e テストで確認
