# 設計書：ルミナリア・テイル ～灯獣の島～

最終更新：2026-11-04（試作版 0.1.0）

## 1. コンセプト

- スマホ縦画面・片手で遊べる、オリジナルのモンスター育成RPG
- 「灯（ともしび）」を胸に宿す生き物＝**灯獣（ともしびけもの）** を捕まえ、育て、進化させる
- ひとり用は完全オフライン。通信（対戦・交換）は QR コードで部屋に入る方式（設計のみ・未実装）

既存作品の名前・キャラクター・地名・技名・音楽は使っていません。灯獣の名前・姿・技・世界観はすべて新規です。

## 2. 世界観とストーリー

| 用語 | 内容 |
| --- | --- |
| 群島ルミナリア | 舞台。いくつもの小島からなる。試作版は最初の島のみ |
| 灯獣 | 胸に「灯」を持つ生き物。灯の色や強さで姿が変わる（＝進化） |
| 灯守（ひもり） | 灯獣と旅をして灯を守る人。主人公は今日、灯守になる |
| ランタン | 弱った灯獣を灯ごと迎え入れる道具（捕獲） |
| 黒霞（くろがすみ） | 灯を弱らせる黒い霧。ふれた灯獣はあばれだす |
| 静夜団（せいやだん） | 「灯さえなければ争いはない」と考え、灯を消して回る集団。首領は「ヨル様」 |
| 夜明けの獣 | 伝説。夜しかなかった空の下で、自分の灯を千に分けて生き物に配った獣 |

### 第1章「ほたる森の 灯」（試作版の範囲）

1. 自分の家で目覚める → 研究所でソラネ博士から相棒（3体から1体）をもらう
2. ライバルのカイトと最初の勝負（負けても話は進む）
3. 博士から依頼：北の「ほたる森」に黒霞が出た
4. そよかぜ草原：見習いトレーナー、花屋、釣り人、迷子のフワモ探し（サブクエスト）
5. ほたる森：静夜団のしたっぱ×2、カイトと協力、3つの灯籠柱に灯をともす（謎解き）→ 黒霞が晴れる
6. 森の主ホタルノオウ戦（ボス）→ 正気に戻り「ほたるのはね」をくれる
7. 博士に報告 → 第1章クリア画面（その後も草原・森で育成とサブクエストを続けられる）

### 登場人物

ソラネ博士（研究所の博士）、カイト（ライバル・幼なじみ）、リンネ（博士の助手・分岐進化のヒント）、ルカ（研究員・サブクエスト）、ミズホ（灯の家＝回復所）、トト（道具屋）、ノノとフワモのモコ（迷子のサブクエスト）、ダン（村の出口の見張り）、ものしりばあさん（伝説を語る）

## 3. ゲームの仕組み

### 属性（9種）と相性

ふつう／ほむら（炎）／しお（水）／めぶき（草）／いかずち（雷）／いわお（岩）／はやて（風）／ひかり（光）／かげ（影）

- ほむら → めぶき → しお → ほむら の三すくみ（最初の3体）
- いかずちは しお・はやてに強く、いわおは ほむら・いかずちに強く、はやては めぶき・いわおに強い
- ひかりとかげは互いに弱点を突き合う
- 効果なし（0倍）は作らない。ばつぐん 2倍／いまひとつ 0.5倍、同じ属性の技は 1.25倍
- 相性表はゲーム内の「図鑑 → 相性表」で見られる。正本は `src/data/elements.ts`

### 灯獣（23種・10系統）

進化の割合は **系統の数で「進化なし 2割・1回進化 5割・2回進化 3割」**（2026-11-04 決定）。`tests/logic.test.ts` で割合が崩れていないか確かめている。灯獣を足す時もこの割合を保つ。

| 区分 | 系統 | 進化 |
| --- | --- | --- |
| 2回進化（3系統＝3割） | ヒノコロ（ほむら）→ カグラビ（ほむら・ひかり）→ ホムラギツネ | Lv14 → Lv32 |
| | シズクン（しお）→ ミナモドラ（しお・いわお）→ ウズシオドラ | Lv14 → Lv32 |
| | メブキン（めぶき）→ イバラジシ（めぶき・いわお）→ ジュカイオウ | Lv14 → Lv34 |
| 1回進化（5系統＝5割） | ピリッチ（いかずち）→ ライメイチョウ | Lv17 |
| | コイシモ（いわお）→ ガンクツモグラ | Lv20 |
| | カザミドリ（はやて・ふつう）→ アラシワシ | Lv18 |
| | ヨイヤミ（かげ・めぶき）→ ヤミトウロウ | Lv22 |
| | **フワモ（ふつう）の分岐進化**（どれか1つ） | あかつきの石（Lv5以上）で ヒカリワタ／ほたる森で Lv16 で カゲワタ／技「つむじかぜ」を覚えて Lv16 で カゼワタ |
| 進化なし（2系統＝2割） | ホタルノオウ | ボス（捕まえられない） |
| | コダマザル（いわお・ふつう） | 登場予定（いわおの山・未実装） |

試作版のマップ（ボス Lv14 まで）では、最終進化（Lv32〜34）・アラシワシ・ヤミトウロウ・コダマザルにはまだ出会えない。データと絵は入っていて、図鑑の番号も振ってある。

分岐進化は、条件を満たした候補が複数あると「どの姿へ進化させる？」の選択画面になり、能力の増減と役割を見比べて選べます。進化はいつでも取りやめでき、あとでメニューの「なかま」から進化させることもできます。

### 戦闘

- 1対1のターン制、なかまは最大3体（4体目からはボックス）
- コマンド：たたかう（技は最大4つ・PP制）／なかま（交代）／どうぐ／つかまえる・にげる（野生のみ）
- 状態異常：やけど・どく・まひ・ねむり・かすみ（命中低下）。同じ属性の灯獣は一部の状態異常にかからない
- 能力変化（±6段階）、急所、命中、素早さ順、先制技
- 経験値は戦闘に出た味方で分け合う。トレーナー戦は1.4倍
- 全滅すると所持金の1/4を落とし、最後に休んだ場所へ戻る（自動セーブ）
- メッセージの速さは3段階＋アニメーション短縮（戦闘中の「はやい」ボタン・SELECTボタンでも切替）
- 画面配置：敵は右上（HPは左上）、味方は左下（HPは右下）、下にメッセージとコマンド。絵とHP表示が重ならないよう `src/ui/battleLayout.ts` の同じ計算で並べる（e2e で重なりを検査）

### 捕獲

- 相手のHPが少ないほど・状態異常があるほど・ランタンが良いほど捕まえやすい（ともしび1倍／あかり1.5倍／たいよう2.2倍）
- 判定は4回、ランタンが最大3回ゆれる演出。計算式は `src/logic/capture.ts`
- 成功率の上限は 85%（`MAX_CAPTURE_CHANCE`）。どんなに弱らせても・良いランタンでも、ランダムで逃げられることがある

### 成長

- レベル上限60。経験値曲線 `0.8 × Lv³`
- 能力値は種族値・レベル・素質（0〜15）から計算
- 技を4つ覚えている時に新しい技を覚えると、入れ替えるか確認する

### マップ・探索

- タップした場所へ歩く（最短経路）。人や物をタップすると、近づいて話す／調べる
- 草むらで野生の灯獣に出会う。トレーナーは視線に入ると近づいてきて勝負になる
- 宝箱、見えない落とし物（キラッと光る）、行き止まりに見える通れる木（隠し通路）
- 試作版のマップ：自分の家、ひだまり村、研究所、灯の家（回復・ボックス・お店）、そよかぜ草原、ほたる森

### クエスト

メイン2本（はじめての灯獣／ほたる森の異変）、サブ6本（迷子のフワモ、図鑑5種、図鑑10種、草原のトレーナー全員、ヨイヤミを見せる、フワモの未来＝進化）。条件を満たすと自動で達成し、ごほうびを1回だけ受け取ります。

### 難易度の目安（`tests/balance.test.ts` で確認）

道具を使わず「いちばん効く技を選ぶ」遊び方での勝率をシミュレーションしています。

| 相手 | 想定 | 勝率の目安 |
| --- | --- | --- |
| 見習いトレーナー ユウ（Lv3×2） | 相棒 Lv5 の1体 | 70〜95% |
| ライバル カイト（Lv4・有利属性） | 相棒 Lv5 | 数〜30%（負けても進む戦い） |
| 森の主（Lv14・ひかり） | 相棒 Lv15＋なかま Lv13×2 | 90%以上 |
| 同上 | 相棒 Lv14＋なかま Lv12×2 | 40〜90% |
| 同上 | Lv9/8 の3体 | 25%未満 |

実際には回復薬・交代が使えるので、上の数字よりやさしくなります。

## 3.5 操作（ゲーム機のようなボタン配置）

画面の上がプレイ画面、下が操作ボタン（`src/ui/gamepad.ts`）。

| ボタン | フィールド | 会話 | メニュー・戦闘のコマンド |
| --- | --- | --- | --- |
| 十字キー | 歩く（押しっぱなしで歩き続ける） | — | ボタンを選ぶ（黄色の枠） |
| A | 話す・調べる | 次へ | 決定 |
| B | — | 次へ | もどる・やめる |
| START | メニュー | — | もどる |
| SELECT | 操作の説明 | — | 戦闘では速さの切り替え |

画面のボタンや行きたい場所を直接タップしても操作できる。

## 4. 画面とデータの分離

- コンテンツ（灯獣・技・道具・相性・マップ・人物・会話・クエスト・お店）は `src/data/` にだけ書く
- 戦闘・捕獲・成長などの計算は `src/logic/`（画面に依存しない。乱数を差し替えてテストできる）
- 見た目（Phaser）と文字・メニュー（DOM）は分離。文字はすべて DOM なので、小さな画面でもにじまず読みやすい

## 5. セーブ

- 保存先：ブラウザの IndexedDB（3スロット＋設定）
- 1回の保存で「本体」と「ひとつ前の本体（バックアップ）」を同時に書き込み、チェックサムで破損を検出。本体が壊れていればバックアップから復元
- 版番号つき。古い版のセーブは移行処理（`MIGRATIONS`）で新しい形式へ変換。新しい版で作られたセーブは読み込まずに案内を出す
- 上書き・削除の前に必ず確認（削除は2回確認）
- 書き出し（ファイル）／読み込み。読み込み時は能力値・技・進化の記録を厳しく検査し、不正なデータは拒否
- 「セーブデータを消されにくくする」（ブラウザの永続化の申請）と、データが消える場合の注意書きを表示

## 6. PWA・オフライン

- `sw/sw-template.js` にビルド時の版とファイル一覧を埋め込み、版ごとの別キャッシュに全ファイルを保存
- 新しい版が届いたら「更新があります」と知らせ、切り替え時は古いキャッシュを消す（新旧が混ざらない）
- 設定画面で「オフラインで遊べるか」を実際のキャッシュ内容から確認して表示
- ひとり用の部分は外部への通信がゼロであることを e2e テストで確認
